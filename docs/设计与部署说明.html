猫眼录屏
体验分析、界面规划与部署说明

本轮完整推翻前版页面，交付直接可编辑、可部署的 HTML 源代码。技术选型为 HTML + 本地 Bootstrap CSS + 原生 JavaScript，不需要任何构建工具。

1. 用户体验分析

用户与需求页面回应关键操作
首次寻找录屏工具：免费吗，有水印吗？首屏下载入口、免费/无水印/本地录制卖点、真实软件界面。看产品 → 下载
学生、教程创作者：能否保留文字与操作画面？学习与创作场景图，区域录制、原始分辨率、MP4/MKV 对比；支持电脑声音、麦克风、混音和音画同步暂停。看场景 → 查指南 → 下载
电脑用户：安装麻烦吗，系统是否支持？安装包、运行环境、安装步骤与实际兼容验证边界。确认要求 → 下载最新安装包 → 安装使用
手机访客：先了解产品，再到电脑安装。单栏自适应、触控导航、复制软件下载地址。复制链接 → Windows 电脑下载
英文访客：需要完整自然的英文说明。独立英文 HTML、同页语言切换、锚点保留，品牌使用 CatEye。切换语言 → 浏览相同页面

核心交互路径：理解价值 → 看到真实界面与适用场景 → 确认功能与系统要求 → 下载 → 查看首次使用指南。没有虚构用户规模、评分、演示视频或性能比例。

3. 高保真 UI 设计

视觉主题为“创作工作室”。区别于前版左右分栏，首屏使用居中大标题与多层真实图片构图；炭黑底色、荧光青柠绿主按钮、浅色场景区交替，建立清晰的阅读节奏。场景照片分别对应学习、视频创作和游戏，软件界面仍使用真实控件导出图。

  • 色彩：炭黑 #111313、青柠绿 #d5fb61、浅色 #f4f5ef。
  • PC 使用宽内容区和网格，手机变为单栏，导航折叠为触控菜单。
  • 图片固定宽高比例，避免加载时页面跳动；正文与实际操作入口使用可读字体尺寸。
  • 按钮、卡片、导航和弹窗共享圆角、细边框、焦点轮廓与交互反馈。
  • 标准系统鼠标样式，无自绘鼠标或跟随指针遮挡操作。

4. 灵动交互与动效

  • 首屏配图缓慢浮动；真实软件图根据鼠标位置轻微倾斜。
  • 卡片局部光晕跟随鼠标，场景图在悬停时缓慢放大。
  • 滚动入场与顶部阅读进度条。
  • 录制步骤点击切换对应说明；MP4/MKV 切换内容、格式与选中状态。
  • 实际软件界面可放大，关闭后焦点回到入口。
  • 原生 FAQ 折叠、手机导航、下载地址复制和真实下载请求反馈。
  • 页脚提供“暂停动效”；尊重 prefers-reduced-motion。手机和触摸设备不启用鼠标视差。

5. 素材与可信度

实际产品图来自 CatEye 项目 WinForms 控件导出；场景图来自 Unsplash 摄影师 Josh Miller、Nick Morrison 和 ARTO SURAJ，场景图不代表 CatEye 软件界面。完整出处见 素材来源与许可。没有使用占位图片、虚构媒体背书或未验证的产品指标。

本轮根据公开 GitHub V2.3.1 更新功能：支持电脑声音、麦克风、同时录制和静音，暂停时音画同步；提供安装包、快捷方式和 Windows 卸载入口，卸载保留录制文件；启动检查与手动检查更新，录制中推迟更新提示。网站描述兼容目标与现有验收范围。

6. 可部署 HTML 交付

直接编辑 HTML；样式位于 assets/css/main.css，动效位于 assets/js/main.js，最新下载位于 assets/js/downloads.js。Bootstrap CSS、Lucide 图标和图片均在本地交付。无需 Node.js、npm、数据库、框架运行时或构建命令。

将完整文件夹上传到静态托管，确保 index.html 是根目录入口并保留 assets。页面全部使用相对路径，支持根目录或子目录部署。页面打开和点击下载时查询 GitHub 最新正式版，自动更新版本、体积与安装包地址。优先 EXE/MSI，同版本无安装器时使用 ZIP；失败提示重试与最新发布页，不回退旧版。仅顶部导航菜单跳转独立下载页，其余下载入口直接请求下载。

7. 验证范围

已检查六个业务页面的 1440 / 768 / 393 / 320px 布局、资源引用、内部锚点、双语覆盖和交互。浏览器测试采用 HTTP 本地预览，并验证 file:// 直接打开首页可获取 GitHub 最新版本信息。最新安装包已从首页实际下载并核对体积与 SHA-256。已验证限流后重试、9 秒超时、便携 ZIP 说明及剪贴板不可用时的手动复制回退。

没有进行实体 iPhone / Android 或全部浏览器真机验收；网站测试不替代 Windows 录屏软件本身的跨系统回归。
