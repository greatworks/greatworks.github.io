找到适合你的清晰度。

MP4

高清省空间

保留原始像素尺寸，使用高质量有损压缩。适合日常记录、演示和分享，通常文件更小。

MKV

原画无损

保留 RGB 像素，适合精细文字、图形与剪辑素材。文件更大，建议用 VLC 或兼容剪辑软件打开。

“原画无损”指视频像素；声音使用 AAC 压缩。文件大小取决于内容、动态程度、时长与帧率，没有固定压缩比例。

还有几个常见问题。

真的完全免费，也没有水印吗？

是的，所有功能免费使用，录制的视频不会添加水印。无需注册账号，也没有订阅门槛。

可以录制声音吗？

支持电脑声音、麦克风、电脑声音 + 麦克风，以及静音录制。暂停时声音和画面同步暂停；录课、会议或讲解都能按需选择。

支持哪些 Windows 版本？

兼容目标为 Windows 7 SP1 / 8 / 8.1 / 10 / 11 的 64 位系统，需要 .NET Framework 4.5.2 或更高版本。已完成 Windows 10 x64 回归，其他目标系统仍需对应设备验证。

录制需要联网吗？文件在哪里？

录制无需联网，视频直接保存在你选择的本地文件夹。检查更新和下载新版才需要网络。

远程操作时，为什么看不到控制条？

部分远程软件会一起隐藏被排除在捕获之外的悬浮条。可使用 Ctrl + Shift + F9 暂停或继续，Ctrl + Shift + F10 停止并保存。
